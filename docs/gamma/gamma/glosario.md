# Glosario
| Palabra | Significado | No confundir con |
|---|---|---|
| Oferta* | Publicación de un puesto o servicio IT. | Búsqueda |
| Búsqueda* | Publicación de alguien que busca trabajo o talento. | Oferta |
| Publicante* | Quien crea una oferta o búsqueda. | Usuario (cualquiera que entra) |
| Talento IT* | Persona del rubro IT que ofrece sus capacidades. | Empresa |
| Rol | Tipo de usuario: talento, empresa, particular, moderador, admin 1, admin 2. | Permiso (algo concreto que un rol puede hacer) |
| Moderador | Rol que revisa publicaciones "en revisión" y las aprueba o rechaza. | Admin |
| Admin nivel 1 | Administra el sistema, p. ej. habilita cuentas. <verificar con Thiago> | Admin nivel 2 |
| Admin nivel 2 | Admin que además puede reportar publicaciones. <verificar> | Admin nivel 1 |
| Habilitar | Aprobar una cuenta nueva para que pueda usar el sistema. | Registrarse |
| Campo privado | Dato del perfil que solo ve su dueño. | Campo obligatorio |
| En revisión | Estado de una publicación que espera la decisión de un moderador. | Rechazada |
| Reporte | Aviso de un admin nivel 2 sobre una publicación problemática. | Rechazo |
| Baja lógica | Marcar algo como eliminado sin borrarlo de la base. | Borrado definitivo |
*Definiciones provisorias: ajustar con modelo-dominio.md.
