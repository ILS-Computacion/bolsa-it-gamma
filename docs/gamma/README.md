# Gamma

## Convención para nombrar ramas

Las ramas de trabajo se nombrarán siguiendo este formato:

`gamma/M1-011-login`

Donde:
- `gamma` identifica al equipo.
- `M1-011` identifica el ticket.
- `login` describe brevemente la tarea.

Cada integrante deberá crear una rama para trabajar y abrir un Pull Request para integrar sus cambios a `main`.
